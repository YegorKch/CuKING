# CuKING

PWA, которая решает, что приготовить: листаешь блюда → «Готовим это» → список продуктов → рецепт по шагам → две оценки.

- Взвешенный рандомайзер: любимые блюда выпадают чаще, недавние (14 дней) не повторяются
- Гарнир подбирается к горячему автоматически, крутится кнопкой ⟳
- 📌 — отложить понравившиеся варианты, ⋯ → «Не предлагать месяц»
- Пересчёт продуктов под число порций
- Рецепт крупным шрифтом, экран не гаснет, шаг сохраняется, если телефон выгрузил приложение
- Работает оффлайн: база хранится на телефоне, записи уходят, когда появится сеть
- Тёмная тема по настройке телефона

## Как устроено

| Слой | Где |
|---|---|
| Рецепты и история | Google-таблица (листы «Блюда», «Ингредиенты», «Шаги», «История», «Справочники») |
| API | Google Apps Script — [gas/](gas/) |
| Приложение | Статика на GitHub Pages: `index.html`, `app.js`, `styles.css`, `sw.js` |
| Начальная база | [data/recipes.py](data/recipes.py) — генерирует xlsx для первого импорта |

Адрес API в код не зашит: он вводится при первом запуске и хранится только на телефоне.

## Обновление приложения

После правок файлов оболочки поднять `VERSION` в [sw.js](sw.js) — иначе телефоны останутся на старой версии из кеша.
Рецепты правятся прямо в таблице, приложение подтягивает их при открытии.
